# Existing taxonomy (London Places/Places)

Snapshot of the values already in use across `London Places/Places/*.md`, as of 2026-09. Re-grep if this looks stale — the vault owner adds and edits notes directly. Use these as the starting point so a new note fits the existing `Places.base` views (which filter/group on `category` and `kind`); only introduce a new value when nothing here actually fits.

## `category` (exactly one of these three)

- `Food` — anywhere you eat or drink: restaurants, cafes, bakeries, pubs, bars, markets selling food, delis.
- `Culture` — things to see/do that aren't primarily about eating: museums, galleries, gardens, parks, viewpoints, landmarks, walks, pubs-as-venues where the point is the building/history rather than the food (note: many pubs are still filed under `Culture`, not `Food` — check a sibling pub note before assuming).
- `Fun` — activities, shopping, ideas/lists, things that don't fit the other two.

## `kind` (pick the closest match; add a new one only if none fit)

Food: Restaurant, Bakery, Pizza, Burger, Mexican, Ramen, Dessert, Sandwich, Deli, Cafe, Market.

Culture: Pub, Garden, Museum, Landmark, Viewpoint, Walk, Park, Gallery, Play.

Fun: Shopping, Shop, Activity, Idea, Date night.

Note: `Date night` is used as a `kind` under `Food` for some upscale restaurants (e.g. Brasserie Zedel, Roebuck) — it overrides the more literal "Restaurant" kind when the note is specifically about a date-night spot. Follow the sibling notes' precedent, not a strict reading of the venue type.
